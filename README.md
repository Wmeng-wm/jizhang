# 记账

一个轻量级的移动端双账户记账 PWA 应用，零依赖，纯前端，数据存储在本地。

## 快速使用

1. 浏览器打开 `index.html` 即可记账
2. 支持添加到手机主屏幕作为 PWA 应用

## iOS 快捷指令（核心功能）

配合 `AI记账.shortcut` 实现 **双击背面 → 截图 → AI自动记账**：

1. 手机设置中配置「背面轻点」触发此快捷指令
2. 支付完成后双击背面，**自动截取当前屏幕**
3. OCR 识别金额、商户等信息
4. 调用 **DeepSeek AI** 智能分析：
   - 自动判断**收支类型**（支出/收入）
   - 自动**分类**（餐饮/交通/购物/网约车/高铁等）
   - 自动选择**账户**（个人/工作）
   - 自动生成**商家备注**
5. 弹出确认框，确认后自动保存

### AI 账户判定规则

| 场景 | 账户 | 分类 |
|------|:---:|:----:|
| 滴滴/网约车/打车 | 工作 | 网约车 |
| 高铁/动车/12306 | 工作 | 高铁 |
| 飞机/机票/航空公司 | 工作 | 飞机 |
| 酒店/宾馆/住宿 | 工作 | 酒店 |
| 出差/报销/公务/公司 | 工作 | 对应分类 |
| 餐饮/外卖/奶茶/咖啡 | 个人 | 餐饮 |
| 淘宝/京东/购物 | 个人 | 购物/超市 |
| 话费/水电/物业 | 个人 | 通讯/住房 |

## 功能

- **双账户管理**：个人 / 工作，独立记账互不干扰
- **收支记录**：支持 10+ 分类的支出和收入
- **明细浏览**：按月分组查看，支持分类筛选、搜索
- **统计报表**：自定义日期范围，分类支出排行 + **环形饼图**
- **AI 智能识别**：搭载 DeepSeek API，自动解析 OCR 文本
- **记录详情**：点击查看该分类的统计数据
- **滑动操作**：左滑编辑/删除
- **导出数据**：CSV（含汇总+明细+分类分析）、JSON 备份/恢复

## 配置 AI

在「我的」页面开启 AI 增强识别，填入 DeepSeek API Key 即可使用。

## 技术栈

- 原生 HTML + CSS + JavaScript（单文件，~1700行）
- 适配 iOS PWA（Safe Area、沉浸式体验）
- 移动端优先设计，最大宽度 430px
- Canvas 原生图表（环形饼图）
- 数据存储：浏览器 localStorage
